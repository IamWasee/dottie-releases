# Dottie

Dottie is a Mac menu bar companion you talk to. Hold **control + option**, ask about what's on your screen, and she answers out loud and points at things with a blue cursor.

This repository only holds Dottie's downloads. Every new version is published under [Releases](https://github.com/IamWasee/dottie-releases/releases), and Dottie updates herself from here.

## Download

**[Download Dottie.dmg](https://github.com/IamWasee/dottie-releases/releases/latest/download/Dottie.dmg)** (macOS 14.2 or later, Apple silicon or Intel).

## Install

1. Open **Dottie.dmg** and drag **Dottie** onto **Applications**.
2. Open Dottie from Applications. The first time, macOS says it can't check Dottie for malware, because Dottie isn't registered with Apple. Click **Done**, open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**, enter your password and click **Open**. You only do this once.
3. Click Dottie's icon in the menu bar and allow **Microphone**, **Accessibility**, **Screen Recording** and **Screen content**.
4. Hold **control + option**, ask something, and let go.

## Updating

Dottie checks for new versions by herself. To check now, open **Home → Settings → Updates**. You can also download the newest Dottie.dmg above and drag it into Applications again, choosing **Replace**.

If something stops working after an update (for example, the shortcut does nothing), open **System Settings → Privacy & Security → Accessibility**, remove Dottie with **−**, and allow it again.
